# 👶👵 Определение возраста по фотографии

### 📝 Описание проекта
Супермаркет внедряет систему компьютерного зрения, фиксирующую лица покупателей в прикассовой зоне. 

Это решение должно помочь:
- анализировать потребительское поведение разных возрастных групп;
- контролировать добросовестность сотрудников при продаже алкоголя.

**Цель:**
Разработать модель, которая по фотографии определяет примерный возраст покупателя.
Требуемое качество модели: MAE ≤ 8 на тестовой выборке.

**Данные:**
Заказчик предоставил набор изображений лиц покупателей с разметкой реального возраста каждого человека.

### 🧰 Основные методы и библиотеки:
- `TensorFlow` / `Keras`
- `ResNet50`
- `ImageDataGenerator`

### 📊 Результаты

- проведена предобработка изображений: ресайз, нормализация, генерация;
- построена модель на основе архитектуры ResNet50;
- финальный слой адаптирован под задачу регрессии;
- модель обучена на 10 эпохах с использованием функции потерь MAE;
- достигнута метрика MAE = 6.36 на тестовой выборке.

Результат удовлетворяет требованиям заказчика (MAE ≤ 8).
