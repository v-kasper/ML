# 🔍 Поиск референсных фотографий по текстовому описанию

### 📝 Описание проекта
Заказчик - фотохостинг для профессиональных фотографов. Пользователи загружают свои снимки, сопровождая их описанием: место съёмки, оборудование, сюжет и пр. Уникальная особенность: описания могут добавлять не только авторы, но и другие участники сообщества.

**Цель исследования:** создать демонстрационную версию поиска изображений по текстовому описанию. Полученный PoC должен доказать, что система поиска референсов по тексту реализуема и перспективна.

**Данные:**

- датасет с именами изображений, ID описания, текст описания;
- разметка соответствий от краудсорсеров;
- разметка от экспертов;
- изображения для обучения;
- тестовые запросы и изображения.

### 🧰 Основные методы и библиотеки
- `SentenceTransformer`
- `ResNet50`
- `Optuna`
- `TensorFlow / Keras`
- `Scikit-learn`
- `PIL`, `NumPy`, `pandas`

### 📊 Результаты

Качество предсказаний не достигло удовлетворительного уровня: модель часто определяет только частичные совпадения или ошибочно считает изображение подходящим.
Получена недостаточная обобщающая способность на новых текстах и сценах.

Проект показал, что концепция поиска изображений по описанию реализуема, но требует доработки: создан демонстрационный PoC, подтверждающий базовую работоспособность подхода.

Дополнительно предложены возможные направления для улучшения качества модели в дальнейшем и альтернативные подходы к решению задачи.
