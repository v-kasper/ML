# 🚕 Оценка риска ДТП по маршруту

### 📝 Описание проекта
Каршеринговая компания планирует создать систему, которая оценивает риск ДТП по выбранному маршруту. Идея — как только водитель бронирует авто и выбирает маршрут, система прогнозирует вероятность ДТП с повреждением машины и, если риск высокий, выдаёт предупреждение и рекомендации.

### 🧰 Основные методы и библиотеки:
- Python, SQLAlchemy
- LightGBM, CatBoost, RandomForest, LogisticRegression
- Optuna 
- SHAP
- Matplotlib, Seaborn, missingno
- Scikit-learn
- Phik

### 📊 Результаты исследования:

- построены три модели: LogisticRegression, RandomForestClassifier, CatBoostClassifier;
- лучшей признана модель CatBoostClassifier с F1 ≈ 0.68 и Accuracy ≈ 0.68 на кросс-валидации;
- метрики на тестовой выборке подтвердили качество модели;
- проведен анализ важности признаков, выявлен ключевой фактор риска — возраст авто;
- сформулированы рекомендации по снижению рисков ДТП и дальнейшему улучшению модели.
