# 🚖 Прогнозирование заказов такси в аэропорту

### 📝 Описание проекта
Сервису такси важно заранее определять периоды пиковой нагрузки, чтобы оперативно привлекать нужное количество водителей. Для этого необходимо построить модель, которая будет прогнозировать число заказов на час вперёд.

**Цель**
Разработать модель, способную предсказывать количество заказов такси на следующий час. Целевая метрика качества — RMSE, не превышающая 48.

**Данные**
Исторические данные о количестве заказов такси по часам.

### 🧰 Основные методы и библиотеки:

- matplotlib, seaborn, plotly
- statsmodels, Prophet, MSTL, AutoARIMA
- mlforecast, Ridge, RandomForest, CatBoost
- TimeSeriesSplit
- optuna

### 📊 Результаты

- обучено 5 моделей: Prophet, ARIMA, Ridge, RandomForest, CatBoost;
- в качестве финальной модели выбрана Ridge, показавшая лучшее соотношение скорости и точности;
- выявлены ключевые паттерны: суточная сезонность и общий восходящий тренд;
- даны рекомендации по улучшению модели.
