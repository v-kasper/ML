# 🔩 Прогноз температуры сплава стали

### 📝 Описание проекта
Металлургический комбинат стремится сократить потребление электроэнергии на этапе обработки стали. Один из способов — контролировать температуру сплава.

**Цель исследования:**
Разработать модель, способную точно предсказывать температуру сплава. Заказчик планирует использовать модель для имитации технологического процесса и дальнейшей оптимизации производства.

**Структура данных:** 

Данные получены в формате SQLite, база состоит из нескольких таблиц:

- данные об электродах;
- объём и время подачи сыпучих материалов;
- параметры продувки газом;
- измерения температуры;
- объём и время подачи проволочных материалов.

### 🧰 Основные методы и библиотеки:
- `Python`, `SQLite`
- `Pandas`, `NumPy`
- `CatBoost`, `RandomForest`, `Keras` / `TensorFlow`
- `Scikit-learn`
- `Optuna`
- `SHAP`, `Phik`
- `Matplotlib`, `Seaborn`, `Plotly`

### 📊 Результаты
- построено несколько моделей, проведён подбор гиперпараметров;
- выбрана модель `CatBoostRegressor()` с результатом `MAE` = 6.144;
- проведён анализ важности признаков — определены ключевые факторы, влияющие на температуру сплава.
