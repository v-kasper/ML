# 🛢 Выбор региона для разработки нефтяных скважин

### 📝 Описание проекта
Добывающая компания планирует открыть новую скважину и хочет определить наиболее выгодный регион для разработки.

**Задача**:
- построить модель, предсказывающую объём нефти в скважинах;
- отобрать 200 лучших скважин в каждом регионе по прогнозируемому объёму;
- рассчитать потенциальную прибыль и риски разработки с помощью бутстрапа.

**Цель**:
Выбрать регион с наибольшей вероятной прибылью и наименьшими рисками убытков.

### 🧰 Основные методы и библиотеки:
- Pandas и NumPy
- Matplotlib и Seaborn
- Scikit-learn
- Phik

### 📊 Результаты
Построена модель линейной регрессии для каждого из трёх регионов. Проведён анализ потенциальной прибыли с использованием техники бутстрапа.

Регион 2 показал лучшие результаты по всем ключевым метрикам:
- максимальная средняя прибыль;
- самая высокая нижняя граница доверительного интервала;
- минимальный риск убытков.

🔍 Вывод:
По результатм исследования выбран регион с наибольшей потенциальной прибылью при минимальных рисках.
