# 🏡 Прогноз стоимости жилья с PySpark

### 📝 Описание проекта

**Цель проекта** — предсказать медианную стоимость жилья на основе данных переписи населения Калифорнии 1990 года.

Для этого использовалась модель линейной регрессии, реализованная в PySpark ML, что позволяет масштабировать решение на большие объёмы данных.

### 🧰 Используемый стек

- PySpark (SparkSession, DataFrame API)
- PySpark ML (Pipeline, LinearRegression, StringIndexer, OneHotEncoder, VectorAssembler, StandardScaler)
- Метрики оценки: RMSE, MAE, R²

### 📊 Результат

- проведена предобработка данных (индексация категориальных признаков, сбор фич в векторы, масштабирование числовых признаков);
- обучены две модели линейной регрессии: на базовом и расширенном наборах признаков;
- оценка модели проведена с использованием RMSE, MAE и R² на тестовой выборке.

Модель, обученная на полном наборе признаков, показала лучшие метрики.
