# 💬 Классификация комментариев: определение токсичности

### 📝 Описание проекта
Интернет-магазин запускает новый сервис с возможностью редактировать и комментировать описания товаров. Чтобы защитить пользователей от токсичного поведения, необходимо автоматизировать процесс модерации.

**Цель**:
Разработать модель машинного обучения, которая классифицирует комментарии пользователей как токсичные или нетоксичные. Требуемая метрика качества — F1 ≥ 0.75.

**Данные**:
Набор данных с текстом комментария и разметкой его токсичности.

🧰 Основные методы и библиотеки:
- `nltk`, `stopwordsiso`, `re`
- `TfidfVectorizer`
- `LogisticRegression()`, `SGDClassifier()`, `LinearSVC()`
- `cross_val_score`, `StratifiedKFold`, `classification_report`
- `Optuna`
- `matplotlib`, `seaborn`, `missingno`

📊 Результаты:

- проведена комплексная предобработка текстов и токенизация;
- обучены 3 модели, гиперпараметры подобраны с помощью `Optuna`;
- достигнута целевая метрика `F1` **0.776**, выбрана модель `SGDClassifier`;
- модель успешно прошла проверку на тестовой выборке, признаки переобучения не выявлены;
- даны рекомендации по дальнейшему повышению качества полученных предсказаний.
