# Проекты по анализу данных и машинному обучению

В этом репозитории собраны проекты, выполненные в процессе обучения и на практике. Каждый из них решает реальную задачу: от поиска токсичных комментариев до прогноза температуры в металлургии.

Проекты сгруппированы по направлениям (EDA, ML, NLP, CV, Time Series), каждый содержит краткое описание, цели, результаты и стэк технологий.

---

| Проект | Направление | Краткое описание | Стэк |

| **📦 Токсичность в комментариях** | NLP + ML | Обнаружение токсичных правок на платформе редактирования товаров | nltk, sklearn, optuna |
| **📸 Поиск по тексту и фото** | CV + NLP | Поиск изображений по описанию для фотохостинга | ResNet, Sentence-BERT, keras, optuna |
