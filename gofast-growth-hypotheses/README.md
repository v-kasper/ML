# 🛴 Статистический анализ данных

**Цель проекта:**
Проанализировать поведение пользователей сервиса аренды самокатов и проверить гипотезы, которые могут помочь увеличить выручку, сократить износ оборудования и сформировать продуктовые рекомендации для бизнеса.

**Описание данных:**

- данные о поездках пользователей;
- информация о наличии подписки;
- сведения о пользователях.

### 📊 Проверенные гипотезы:

1. Пользователи с подпиской тратят больше времени на поездки

✅ Подтверждено. Рекомендация: активно продвигать подписку — это увеличит выручку не только от подписки, но и от времени поездок.


2. Пользователи с подпиской проезжают больше оптимального расстояния в 3130 м

❌ Не подтвердилось. Подписчики используют самокаты оптимально с точки зрения износа.

3. Выручка от пользователей с подпиской выше, чем без подписки

✅ Подтверждено. Подписка приносит больший месячный доход.

### 🧰 Основные методы и библиотеки:
- `pandas`, `numpy`
- `scipy.stats`, `math`
- `matplotlib`, `seaborn`, `missingno`
