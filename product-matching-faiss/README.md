# 🔍 Поиск похожих товаров (мэтчинг)

### 📝 Описание проекта
Интернет-магазины часто сталкиваются с задачей подбора похожих товаров — например, чтобы предлагать альтернативы, если товар закончился, или улучшить рекомендации. В рамках проекта требуется разработать алгоритм, который на основе признаков товара сможет находить наиболее похожие позиции из каталога.

**Цель**:
Разработать модель мэтчинга, которая для каждого товара будет находить 5 наиболее похожих товаров по вектору признаков.

**Данные**:

- база товаров (id + 72 признака);
- тренировочный набор: товар, его вектор признаков и id наиболее похожего товара из base.csv (по мнению экспертов);
- товары, для которых необходимо найти похожие из base.csv;
- правильные ответы для валидации.

*Примечание*: Из-за размера файла base.csv (база товаров) в репозиторий добавлена его уменьшенная версия. Ссылки на полные датасеты находятся в ноутбуке проекта.

### 🧰 Основные методы и библиотеки:
- Pandas и NumPy
- FAISS (Facebook AI Similarity Search)
- Scikit-learn
- Phik
- Matplotlib, Seaborn

### 📊 Результаты
Разработана и оптимизирована модель поиска ближайших соседей с использованием библиотеки FAISS. Она продемонстрировала следующие результаты:

Accuracy@5 на тестовой выборке: 78.15%

🔍 Вывод:
Модель позволяет эффективно находить похожие товары, что может быть полезно для внедрения в системы рекомендаций и карточки товара. Также предложены направления доработки модели для повышения точности.
