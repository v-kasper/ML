# 🛍 Персонализация предложений для интернет-магазина

### 🔍 Задача проекта

Разработать модель, которая поможет определить, какие клиенты с наибольшей вероятностью совершат покупку. Результат работы модели поможет интернет-магазину персонализировать предложения и повысить вовлечённость постоянных клиентов.

### 💡 Применение результатов

Модель используется для таргетированных маркетинговых коммуникаций: письма, пуш-уведомления, специальные предложения. Цель — вернуть пользователей на сайт и стимулировать повторные покупки.

### 🚀 Цель проекта

Создание модели, которая позволит предсказывать покупательскую активность клиента на основе данных о его взаимодействии с сайтом.

### 📦 Данные

В проекте использовались данные:
- о поведении покупателя на сайте;
- о коммуникациях с покупателем;
- о продуктовом поведении;
- о выручке, которую получает магазин с покупателя;
- о времени, которое покупатель провёл на сайте;
- о среднемесячной прибыли покупателя за последние 3 месяца.

### 🧰 Основные методы и библиотеки:
- Pandas и NumPy
- Scikit-learn (LogisticRegression, DecisionTreeClassifier, KNeighborsClassifier, SVC и др.)
- SHAP
- Phik
- Matplotlib и Seaborn
- missingno

### 📊 Результаты

Построен общий пайплайн с подбором гиперпараметров для четырёх моделей. 
Лучшая модель выбрана по результатам сравнения с использованием метрики ROC-AUC:
- ROC-AUC на валидационной выборке: 0.92
- ROC-AUC на тестовой выборке: 0.91

Анализ важности признаков с помощью SHAP показал, что активность клиентов (кол-во просмотренных страниц и категорий, время посещения сайта) оказывает наибольшее влияние на предсказания модели, в то время как предпочтения по категориям товаров — минимальное.

На основании полученных выводов составлены рекомендации по повышению покупательской активности.
