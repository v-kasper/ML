# 🚀 Прогноз закрытия стартапов

### 📝 Описание проекта
Цель исследования — создать модель, способную предсказать, какие стартапы с большей вероятностью закроются, чтобы минимизировать риски инвестиций.

**Входные данные**:
Историческая информация о стартапах, функционировавших с 1970 по 2018 год. В том числе: срок существования, завершение финансирования, отрасль, география и другие признаки.

### 🧰 Основные методы и библиотеки:
- Pandas, NumPy, SciPy
- Matplotlib, Seaborn, SHAP
- Phik
- Optuna
- CatBoostClassifier
- Scikit-learn
- imbalanced-learn

### 📊 Результаты

Выбрана модель для построения прогноза. Качество моделей оценено с помощью метрики `F1-Score`.
Метрика `F1-score` лучшей модели `CatBoostClassifier()` на валидации — 0.972

Оценка важности признаков проведена с помощью `SHAP`.
Визуализация важности признаков — с помощью `shap.plots.bar` и `shap.plots.beeswarm`.

🔍 Ключевые выводы:

Наиболее важным фактором, по мнению модели, является срок жизни стартапа — как в целом, так и после завершения последнего раунда финансирования.
Модель считает перспективными те компании, которые уже долго существуют и недавно привлекли инвестиции.
